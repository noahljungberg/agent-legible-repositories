# Contributing

Contributions should improve agent legibility: clearer routing, stronger citations, better operational guidance, or better verification.

## Good Contributions

- Add or update citations to relevant agent-engineering research.
- Clarify the paper without making it longer than necessary.
- Improve `SKILL.md` so agents can apply the framework more reliably.
- Add checks or workflows that keep the paper and repo easy to maintain.

## Before Opening A Pull Request

1. Keep the repository domain-neutral.
2. Avoid private examples, private paths, secrets, or implementation-specific lore.
3. Run `make paper` if you have LaTeX installed.
4. If the paper changes operational guidance, update `SKILL.md` or `CHECKLIST.md` too.
